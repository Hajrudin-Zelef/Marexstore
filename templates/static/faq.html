Questions fréquentes

Commander sur Marexstore, suivre un colis, payer, utiliser un code promo : tout ce qu'il faut savoir.

Comment passer commande ?

Ajoutez vos produits au panier, puis cliquez sur « Commander sur WhatsApp » : votre panier est envoyé à notre équipe, qui confirme la commande avec vous. Vous pouvez aussi demander un devis depuis la page Devis.

Faut-il créer un compte ?

Non, le compte est optionnel. Avec un compte, vous retrouvez vos coordonnées, vos commandes, vos adresses et vos paniers sauvegardés sur la page Mon compte.

Quels moyens de paiement acceptez-vous ?

Selon les réglages de la boutique : WhatsApp, Orange Money, MTN Mobile Money, Wave, Moov Money et paiement à la livraison. Le moyen choisi est rappelé dans le message WhatsApp envoyé à notre équipe.

Comment utiliser un code promo ?

Saisissez votre code dans le champ « Code promo » du panier avant de commander : la remise est appliquée automatiquement par la boutique et rappelée dans le message envoyé. Un code peut être limité en nombre d'utilisations ou avoir une date d'expiration.

Comment suivre ma commande ?

Sur la page Suivi de commande avec votre numéro de commande, ou contactez-nous directement sur WhatsApp au (+225) 07 05 08 75 07.

Livrez-vous hors d'Abidjan ?

Oui, nous livrons partout en Côte d'Ivoire. Les frais et délais sont confirmés avec notre équipe sur WhatsApp au moment de la commande.

Et si un produit ne me convient pas ?

Contactez-nous rapidement via la page Contact en précisant votre numéro de commande : nous trouvons ensemble une solution (échange, avoir ou remboursement selon le cas).
