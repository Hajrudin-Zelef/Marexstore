Front — personnaliser le site

Le cœur du Studio : le design de tout le site (boutique, fiches, panier…), en interface pour les juniors ou en code pour les seniors. L'aperçu à droite est le vrai site — il se met à jour en direct.

Pour corriger une faute ou changer un libellé : modifiez le texte ici, l'aperçu à droite suit en direct. C'est le même texte que dans l'onglet Textes.

Un senior ne code jamais dans le vide : voici les fichiers du site. Cliquez un fichier pour l'ouvrir, modifiez-le, puis Publiez. Le CSS s'applique à l'aperçu en direct.
